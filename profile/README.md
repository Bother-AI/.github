# 🦫 Bother-AI — 바더(저나바더)

> 쓰는 일기는 3일, 걸려오는 일기는 365일.

**바더**는 매일 정해진 시간에 AI가 먼저 전화를 걸어 5분 대화하고, 그 대화를 1인칭 일기로 정리해 주는 **AI 전화메이트 & 자동 일기** 서비스입니다.

- 📞 AI가 먼저 걸어오는 5분 통화
- 📔 통화 3분 뒤 도착하는 나만의 말투 일기
- 📊 주간 감정 리포트
- 🏠 비버 집 짓기 — 통화할수록 자라는 비버의 집
- 🎞️ 오늘의 컷 — 하루를 네컷만화·그림일기로

## Repositories

| 레포 | 역할 |
| --- | --- |
| `bother-poc` | 기술 PoC (실시간 음성 · STT/TTS · 이미지 생성) |
| `bother-app` | 모바일 앱 (iOS · Android) |
| `bother-server` | API 서버 · 발신 스케줄러 · 통화/일기 AI 파이프라인 |
